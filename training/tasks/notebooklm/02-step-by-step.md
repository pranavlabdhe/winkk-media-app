# Tasks module — step by step

Use this as the click path for the video. Labels match the application.

## 1. Open the task board

1. Sign in.
2. In the top navigation, choose **Tasks**.
3. The page title is **Client-wise Task Board**.

You will see:

- A filter row: **All clients**, **All assignees**, **All categories**, **All statuses**, **Apply filters**, **Clear**.
- A create form: **Task title**, **Assign to**, category, **Client (optional)**, due date, status, description, blogger, activity date, and **Link an existing module record**.
- One card per task with the owner, client, category, due date, status, linked records, update controls, and activity history.

## 2. Filter the board

1. Choose a client, for example **Solhaus**.
2. Choose a category, for example **Social Media**.
3. Choose a status, for example **In progress**.
4. Click **Apply filters**.

The board now shows only tasks that match **all three** filters. Use **Clear** to return to the full board.

You can also filter by **Assigned to me**, or open a single task with its own link.

## 3. Create a task

1. In the create form, type the **Task title**.
2. Choose **Assign to**.
3. Choose the category that describes the work.
4. Choose the client.
5. Set a due date and status.
6. Add a description or client instruction.
7. Click **Create task**.

If the category is Social Media, Feedback, Client Communication, Blogger Collaboration, or Meeting, and the task has a client, the matching module record is created automatically.

If you leave the category as Design, Strategy, Operations, or Other, the task is created without a module record.

## 4. Link an existing record instead

If the post, feedback, communication, blogger assignment, or meeting already exists:

1. Open the **Link an existing module record (optional)** dropdown.
2. Choose the record.
3. Create the task.

The app links the existing record instead of creating a duplicate.

## 5. Work a single task

Open a task from the board. The URL ends with `?task=<number>`, which focuses the board on that task.

On the card you can:

- Read the assignee, client, category, due date, and status.
- See **Created from …** when the task came from another module.
- See **Follow-up of …** when a meeting created a follow-up task.
- Open **Linked records**.
- Read the **Activity history**.
- Update status, assignee, category, and due date.
- Add a progress note or blocker.
- Delete the task while keeping the linked records.

## 6. Update status

1. In the task card, open the status dropdown.
2. Choose **Done**.
3. Click **Update**.

What happens:

- The task status becomes Done.
- The linked Social Post changes to Published.
- The linked communication, feedback, blogger assignment, or meeting changes to its matching status.
- The activity history records the status move.
- The client timeline shows the update.

## 7. Add a note

1. In **Activity history**, type a short note.
2. Click **Add note**.

Good notes explain a decision, a blocker, or a handoff. They are not a chat replacement.

## 8. Delete a task safely

1. Click **Delete task (keeps linked records)**.
2. The task is removed.
3. The linked post, feedback, communication, blogger assignment, or meeting is kept and unlinked.

This protects work that has already happened, such as a published post or a completed meeting.

## 9. Where to go next

- **My Work** shows the employee’s own tasks.
- **Social Posts**, **Feedback**, **Communications**, **Bloggers**, and **Meetings** show the connected records.
- The **client page** shows the unified timeline.
